FLOW B · Cloud Chat & Public `/v1/chat/completions` API Request ☑ LIVE TODAY
STEP 1 · AUTH & IP SEALValidates rc_sk_* API key or stateless rc_ws HMAC cookie + signed $5.00 trial IP cap.
STEP 2 · CREDIT RESERVEpatsum atomically reserves wallet/allowance budget and writes lock-free AssistantJob to Neon DB.
STEP 3 · PARETO + FAILOVER32-slot worker claims job, scores 48 task groups, routes to fastest/cheapest model (<120ms failover on 5xx).
STEP 4 · SETTLE & SIGNStreams SSE response, settles exact spend, strips wholesale COGS, and signs Ed25519 receipt + Merkle STH.
FLOW C · Governed Multi-Step Workflow Automation (e.g., Stripe → Slack → Neon DB) ☑ LIVE TODAY
STEP 1 · DESIGN IN HUBUser creates routine in the 4-tab Workflows Hub (AI Chat Builder, Step Editor, or Visual Node Canvas).
STEP 2 · DRY-RUN CONTRACTStation (:8799) checks connected app keys and shows blast radius (egress domains, spend) with zero live side effects.
STEP 3 · PLAN-ROOT PINUser approves workflow, pinning its cryptographic plan_root hash. Any step change forces re-approval.
STEP 4 · WRITE AIRLOCKReads run immediately; external writes (email, Slack, DB write) pause for human approval and emit node receipts.
FLOW D · $0.00 Private On-Device Mac Execution & Mozart Sub-Agents ☑ LIVE TODAY
STEP 1 · AUTO-SIZE PACKwhitelabel-autopull.js checks Mac RAM & free disk to install matching Qwen GGUF models on 127.0.0.1:11434.
STEP 2 · LOOPBACK ROUTE$0 Local mode or mozart_local_swarm.py routes strictly over 127.0.0.1 (:8799/v1 / :11434).
STEP 3 · GPU EXECUTIONRuns 0.8B (258 t/s), 4B (130 t/s), 20B (109 t/s), 30.5B Coder (119 t/s), or 79.7B Coder (262K ctx) at $0.00.
